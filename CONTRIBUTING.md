# Contributing to Network Application AnalyzerThank you for your interest in contributing to Network Application Analyzer.## Reporting IssuesBefore creating a new issue:- Verify that the issue is reproducible.- Check whether the problem already exists in the issue tracker.- Include relevant logs and screenshots when possible.Please provide:- Windows version- PowerShell version- Analyzer version- Reproduction steps- Expected behavior- Actual behavior## Feature RequestsFeature requests are welcome.Please describe:- The use case- Why the feature is useful- Any implementation ideas you may have## Development Guidelines### PowerShell VersionThe project currently targets:- Windows PowerShell 5.1Compatibility with PowerShell 7 is welcome but should not break PowerShell 5.1 support.### Coding Style- Use `Set-StrictMode -Version Latest`- Use descriptive function names- Prefer small, focused functions- Use approved PowerShell verbs- Handle errors gracefully- Maintain readable formatting### LoggingNew functionality should integrate with the existing logging framework where appropriate.### TestingWhen submitting changes, test with at least one real-world application.Examples:- Google Earth Pro- Bambu Studio- ifolor Designer- Microsoft Edge## Pull RequestsBefore submitting a pull request:- Verify the solution works as expected- Update documentation if required- Keep changes focused and limited in scope- Avoid unrelated formatting changes## DocumentationDocumentation improvements are always welcome.Examples:- README updates- Usage examples- Screenshots- Troubleshooting guidance- Confluence-style operational documentation## Code of ConductPlease be respectful and constructive when interacting with other contributors.Thank you for helping improve Network Application Analyzer.
